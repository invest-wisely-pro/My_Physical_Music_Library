# My Physical Music Library

A private, offline-first web app for physical music collectors (vinyl, CD, cassette): exact editions from MusicBrainz (also by barcode), tracklists, full credits (producers, mastering, musicians), Goldmine grading, stats. No API keys, data stays on the device. Covers from the Cover Art Archive.

**Monthly offline index** — `.github/workflows/aggiorna-musica.yml` rebuilds an index of the ~80,000 most widespread albums from the official MusicBrainz JSON dump (CC0) on the 5th of every month.
